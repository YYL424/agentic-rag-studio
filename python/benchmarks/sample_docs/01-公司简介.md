# 星云科技公司简介

星云科技成立于2018年3月，总部位于上海张江高科技园区，是一家专注于企业级知识管理平台的人工智能公司。公司注册资本5000万元人民币，现有员工320人，其中研发人员占比68%。

## 发展历程

2018年，公司完成天使轮融资800万元，推出第一代文档检索产品，主要服务于金融行业客户。2019年，完成A轮融资5000万元，产品升级为多模态文档解析引擎，支持PDF、Word、PPT和图片的自动结构化。2020年，完成B轮融资2亿元，发布知识图谱构建平台，将实体抽取和关系推理引入知识管理流程。

2021年，公司营收突破1.2亿元，客户数量达到180家，覆盖金融、制造、医疗三大行业。2022年，发布自研大模型应用框架，支持私有化部署的智能问答系统。2023年，完成C轮融资5亿元，估值达到35亿元，研发团队扩展至220人。2024年，海外业务启动，在新加坡设立亚太总部，服务东南亚市场的12家金融机构。

## 组织架构

公司采用扁平化管理结构，设五个一级部门。技术中心下设算法组、平台组和基础设施组，负责核心产品的研发。产品中心负责需求分析和产品设计，包括企业知识库产品线和智能问答产品线。销售中心按行业划分团队，分别服务金融、制造、医疗客户。运营中心负责客户成功和内容运营。职能中心涵盖人力资源、财务和法务。

算法组现有45人，负责文档解析、信息抽取、检索排序等核心算法的研发。平台组38人，负责微服务架构、API网关和部署运维。基础设施组25人，负责GPU集群、数据存储和网络安全。

## 企业愿景

公司的使命是"让每一份企业文档都能被理解和应用"。长期目标是成为企业级知识智能领域的标杆，在2028年前服务1000家大型企业客户。公司的技术价值观强调三个原则：模型私有化部署优先、数据不出企业内网、所有能力提供开放API。公司每年将营收的25%投入研发，拥有发明专利32项、软件著作权58项。

在人才培养方面，公司与上海交通大学、复旦大学建立了联合实验室，每年接收实习生60名。公司推行技术职级体系，从T1到T10共十级，工程师可以走技术专家路线而不必转管理岗。每年6月和12月进行两次职级评审，评审委员会由各中心的技术负责人组成。
