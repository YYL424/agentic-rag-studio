# 星云知识中台 3.0 产品白皮书

星云知识中台3.0是企业级知识管理的一站式平台，提供文档解析、智能检索、知识图谱和智能问答四大核心能力，支持私有化部署和混合云部署两种模式。

## 文档解析能力

系统支持PDF、Word、PPT、Excel、图片和Markdown共六种格式的自动解析。PDF解析采用四级降级策略：首选marker-pdf引擎进行结构化提取，保留标题层级、表格和公式；其次使用docling引擎处理复杂版式；再次使用pymupdf进行文本和表格提取；最后使用pypdf做纯文本兜底。OCR引擎支持中英文共132种字体识别，表格识别准确率达到98.2%。

扫描件处理方面，系统内置图像预处理管线，包括去噪、倾斜校正和版面分析，手写体识别准确率在医疗单据场景达到91.5%。单页解析平均耗时0.8秒，支持单文件最大500MB、批量上传每次最多200个文件。

## 智能检索能力

检索模块支持向量检索、全文检索和图谱检索三种模式的混合召回。向量检索使用BGE系列嵌入模型，支持中英双语语义匹配，向量维度1024维。混合检索通过加权粗排和重排模型精排两级排序，重排采用bge-reranker-v2-m3交叉编码器，在中文公开评测集上MRR提升47.9%。检索延迟P95控制在900毫秒以内。

系统支持Self-RAG自适应检索：当首轮检索结果与问题的相关性评分低于0.6时，自动改写查询进行第二轮检索，最多重检2轮。相关性评分由大模型实时评估，改写策略会结合已检索内容的缺失信息点进行补全。

## 知识图谱能力

图谱构建管线包含实体识别、关系抽取和实体消解三个步骤。实体识别支持人名、机构名、产品名、技术名词共18种实体类型。关系抽取覆盖组织关系、从属关系、依赖关系等12种关系类型。实体消解采用向量相似度和规则匹配的联合策略，同名实体的合并准确率为94.3%。

图存储使用Neo4j，支持Cypher查询语言，提供可视化图谱浏览界面。图谱规模可扩展到10亿实体、50亿关系，查询响应时间中位数120毫秒。

## 智能问答能力

问答系统采用检索增强生成架构，通过LangGraph编排状态机，支持意图识别、查询改写、并行检索和答案生成四个阶段。答案生成强制引用检索上下文，未命中相关知识时会明确告知用户。系统支持流式输出，首字延迟中位数600毫秒。

人机协同方面，系统提供入库审核机制，高风险知识的抽取结果需人工确认后才能写入知识库。审核界面支持批量通过、单条驳回和修改后入库三种操作。

## 性能指标

在8卡A100集群上，系统支持每秒1200次并发检索请求，单知识库最大支持5000万文档块。全链路可用性达到99.95%，数据备份采用每日全量加实时增量的双保险策略，恢复时间目标为15分钟。
