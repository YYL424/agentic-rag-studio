# 星云科技客户案例集

本案例集收录了星云科技在金融、制造、医疗三大行业的典型客户实践，每个案例包含项目背景、实施方案和量化收益。

## 金融行业案例：华信银行

华信银行是一家资产规模超过3万亿元的股份制商业银行，拥有8万名员工和2000多个内部制度文档。项目启动前，员工平均每次查找内部制度需要15分钟，客服人员回答业务问题经常需要翻阅三个以上的系统。2022年9月，华信银行与星云科技合作建设统一知识服务平台。

实施方案分为三个阶段。第一阶段耗时两个月，完成了120万份历史文档的结构化解析，建立了覆盖信贷、运营、合规三大领域的知识库。第二阶段上线智能问答机器人，接入内部办公平台，支持员工用自然语言提问。第三阶段打通客服系统和业务系统，实现业务办理过程中的实时知识推荐。平台上线后，制度查找时间从15分钟下降到40秒，客服首次解决率从68%提升到89%，每年节省人工成本约2400万元。

## 制造行业案例：华东重工

华东重工是国内领先的重型机械制造商，年产值180亿元，在全国有6个生产基地。公司积累了40年的工程图纸和技术文档，总量超过50万份，分布在12个独立的文件服务器中。工程师查找历史技术文档平均需要两天时间，重复设计的浪费每年约5000万元。

星云科技为华东重工部署了图纸智能检索系统，重点解决CAD图纸和工艺文档的跨库检索。系统将12个文件服务器的文档统一接入知识中台，对图纸中的标题栏、技术要求文字进行OCR识别，建立图纸与工艺文档的关联图谱。系统上线一年后，技术文档查找时间从两天缩短到10分钟，重复设计率下降35%，累计节约设计成本3800万元。华东重工已将系统扩展至供应商管理场景，支持采购部门快速检索供应商资质和物料历史。

## 医疗行业案例：仁和医院集团

仁和医院集团旗下有5家三甲医院和12家社区医院，年门诊量超过800万人次。集团面临的核心痛点是医学知识分散：临床指南、药品说明书、医保政策分属不同部门维护，医生在诊疗过程中难以快速获取权威信息。2023年4月，集团启动临床知识助手项目。

项目采用私有化部署方案，所有患者数据和医学文献均存储在集团内网。知识库首批接入4000份临床指南、2万份药品说明书和全部医保政策文件。系统为医生提供诊疗环节的实时知识推荐：在电子病历系统输入诊断时，自动推送相关指南要点和用药注意事项。项目上线6个月后，医生查阅指南的平均时间从8分钟下降到30秒，用药差错率下降42%，患者平均候诊时间缩短18分钟。集团计划在二期将系统扩展到护理和检验科室。

## 跨行业观察

通过对180家客户的交付数据分析，星云科技总结出三条规律。第一，知识检索类项目平均投资回报周期为11个月，其中金融行业最短为8个月。第二，项目成功的关键因素中，数据治理质量占40%，用户习惯培养占30%，技术选型仅占30%。第三，私有化部署需求占比达到86%，数据安全是企业客户的第一考量。这些规律已沉淀为公司的行业知识库，指导新项目的实施方法。
